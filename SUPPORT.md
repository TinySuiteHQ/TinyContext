# Support policy

TinyContext is part of TinySuite. It is built in the EU, maintained from Vienna,
Austria, and meant to be maintained for the long run.

## What to expect

- **Releases:** every release is published on
  [GitHub Releases](https://github.com/TinySuiteHQ/TinyContext/releases) with
  notes, to PyPI as `tinysuite-context`, and to Docker Hub as
  `marcellm01/tinycontext`.
- **Versions:** only the latest release is supported (see
  [SECURITY.md](SECURITY.md) for security fixes). Please upgrade before
  reporting a bug.
- **Issues:** new issues are triaged on a best-effort basis, typically within
  a week. This is a small project, so there is no guaranteed response time.
- **Security reports:** use private
  [GitHub Security Advisories](https://github.com/TinySuiteHQ/TinyContext/security/advisories/new),
  not public issues.
- **Dependencies:** kept current through Dependabot and CI.

## Asking for help

- Bugs and feature requests: [open an issue](https://github.com/TinySuiteHQ/TinyContext/issues/new/choose).
- Include your version (`pip show tinysuite-context`), install tier
  (library, MCP, or Docker), and the output of `tinycontext doctor`.

## If maintenance status changes

If the project ever becomes unmaintained, this page will be updated to say so.
